⬇️
2
🔧 Advanced Data Preprocessing
System validates, cleans, and transforms input data using sophisticated preprocessing pipeline.

Processing Steps:

  • Validation: Range checks, data type validation, business rule enforcement
  • Imputation: Missing values filled with portfolio medians from training data
  • Standardization: Numeric features scaled using training distribution parameters
  • Encoding: Categorical variables converted to one-hot encoded features
  • Feature Alignment: Ensures exact match with training feature set (22 features)
⬇️
3
🤖 Machine Learning Prediction
Enhanced RandomForest model processes features to generate probability and binary predictions.
Model Type: RandomForest Classifier
Estimators: 160 trees
Max Depth: 12 levels
Training Records: 116,058 loans
Feature Count: 22 total (16 numeric + 6 categorical)
Class Balance: 69% default, 31% on-time
⬇️
4
📊 Comprehensive Risk Analysis
System performs detailed risk assessment including driver analysis and confidence scoring.

Risk Level Classification:

Low Risk
< 25%
Moderate Risk
25% - 50%
High Risk
50% - 75%
Critical Risk
≥ 75%

Driver Analysis:

  • Z-Score Calculation: Deviation from portfolio medians
  • Feature Importance: Model-derived feature weights
  • Risk Direction: Higher/Lower risk contribution
  • Top 5 Drivers: Most influential factors for this prediction
⬇️
