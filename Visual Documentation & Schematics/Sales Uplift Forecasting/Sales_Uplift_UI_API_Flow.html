📊 Sales Uplift Forecasting - UI/API Flow

Interactive Sequence Diagram for Sales Prediction System

📋 How it Runs (UI and API)

  • Sales Forecasting: Dashboard → "Sales Uplift Forecasting" → forecast page loads
  • Prediction Setup: Fill product, store, date parameters → click Forecast → server analyzes trends, seasonality → returns uplift predictions
  • Batch Forecasting: Upload CSV with historical sales data → receive download link with uplift forecasts and business insights

🔄 Individual Sales Forecast Flow

👤 User
🖥️ Dashboard
(iframe)
📊 Sales Flask
(Port 7003)
1
Click "Sales Uplift Forecasting"
2
GET /sales-forecast
3

4
POST /predict (product_data, store_info, time_params, model_type)

5

📤 Input Parameters

POST /predict { "store_id": "Store_001", "product_category": "Electronics", "item_name": "Samsung Galaxy", "forecast_date": "2025-12-01", "forecast_period": 30, "model_type": "ensemble", "historical_sales": [1200, 1350, 1180, 1420], "seasonality_factor": "high", "promotion_planned": true }

📥 Response Format

{ "predicted_sales": 1680, "baseline_sales": 1400, "uplift_percentage": 20.0, "confidence_score": 0.87, "revenue_impact": "+$28,000", "trend_analysis": "Positive growth trend", "recommendations": [ "Optimal time for promotion launch", "Increase inventory by 25%", "Focus on digital marketing" ] }
