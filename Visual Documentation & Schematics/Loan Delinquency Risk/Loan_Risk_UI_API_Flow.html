🏦 Loan Delinquency Risk - UI/API Flow

Interactive Sequence Diagram for Risk Assessment System

📋 How it Runs (UI and API)

  • Individual Assessment: Dashboard → "Loan Risk Assessment" → form page loads
  • Fill Details: Personal info, employment, financial data → click Predict → server processes features → returns risk score
  • Batch Processing: Upload CSV with customer data → receive download link for risk predictions

🔄 Individual Risk Assessment Flow

👤 User
🖥️ Dashboard
(iframe)
🏦 Loan Risk Flask
(Port 5001)
1
Click "Loan Risk Assessment"
2
GET /loan-risk
3
HTML Form (Risk Assessment)
4
POST /predict (personal_data, employment, financial)
🤖 ML Processing: Feature engineering → TabPFN + Ensemble → Risk Score Calculation
5
Risk Score + Decision + Recommendations

📤 Input Parameters

POST /predict { "age": 35, "income": 50000, "employment_type": "Permanent", "credit_score": 720, "loan_amount": 25000, "loan_purpose": "Home", "existing_debt": 5000 }

📥 Response Format

{ "risk_score": 0.23, "risk_level": "Low Risk", "decision": "APPROVED", "confidence": 0.89, "recommendations": [ "Standard interest rate applicable", "No additional collateral required" ] }
