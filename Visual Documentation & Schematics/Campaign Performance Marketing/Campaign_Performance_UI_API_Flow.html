📈 Campaign Performance Marketing - UI/API Flow

Interactive Sequence Diagram for Marketing Analytics System

📋 How it Runs (UI and API)

  • Campaign Analysis: Dashboard → "Campaign Performance" → analysis page loads
  • Store Performance: Fill store details, campaign data → click Analyze → server processes features, campaigns → returns performance insights
  • Batch Analysis: Upload CSV with store/campaign data → receive download link with performance analysis

🔄 Store Performance Analysis Flow

👤 User
🖥️ Dashboard
(iframe)
📈 Campaign Flask
(Port 7002)
1
Click "Campaign Performance"
2
GET /campaign
3
HTML Form (Campaign Analysis)
4
POST /analyze (store_data, campaign_metrics, market_data)
🤖 ML Processing: Feature engineering → CatBoost + LightGBM + Ridge + TabPFN → Performance Score
5
Performance Score + ROI Analysis + Recommendations

📤 Input Parameters

POST /analyze { "store_id": "ST001", "store_type": "Flagship", "location": "Urban", "sales_volume": 150000, "campaign_spend": 25000, "impressions": 500000, "click_rate": 0.035, "conversion_rate": 0.028, "seasonality": "High" }

📥 Response Format

{ "performance_score": 0.78, "performance_rank": "Top 15%", "roi_analysis": { "current_roi": 3.2, "predicted_roi": 4.1, "improvement": "+28%" }, "recommendations": [ "Increase digital spend by 15%", "Focus on mobile campaigns", "Optimize for conversion rate" ] }
