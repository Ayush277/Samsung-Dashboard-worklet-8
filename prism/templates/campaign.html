Uplift is measured now; it used to be invented.

The previous version derived a baseline from store_id % 10 and item_id % 20, and a "conversion probability" from 0.8 + (store_id % 7) * 0.1 — arbitrary arithmetic on an ID, labelled in the source as "simulate store quality impact" and shown to users as AI output. Store 8 outranked store 7 because 8 % 7 is 1. This console compares against the real mean for that store and item instead. Conversion probability is gone entirely: no dataset in this project records impressions, clicks or conversions, so there is nothing to predict it from. See the model card.
